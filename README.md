# bacterial-AST-analysis

This repository contains scripts used to analyze antimicrobial susceptibility data and generate figures.

Preprint Link: 
https://www.biorxiv.org/content/10.1101/2025.08.31.673274v1

## Contents

- Mean inhibition zone calculation
- Standard deviation heatmap generation
- Phenotype–genotype comparison plots

## Requirements

Python 3.9+
pandas
matplotlib
plotly

## Note

Raw data are not included due to publication policy.
